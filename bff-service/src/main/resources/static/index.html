Financial API · BFFdemo

Demo publica de un reto tecnico en Java 17 / Spring Boot 3.5 reactivo. El BFF recibe el codigo de cliente cifrado en AES, lo descifra y llama en paralelo (Mono.zip) a dos microservicios sobre PostgreSQL con R2DBC. Datos ficticios, solo lectura.

Navegador→ bff-service→ Mono.zip → customer-service financial-products-service → PostgreSQL (R2DBC)

1 · Clientes de demo

Cada tarjeta lleva el codigo cifrado que espera el BFF. Al pulsarla se llama a GET /api/customer-info/{codigoCifrado}.
